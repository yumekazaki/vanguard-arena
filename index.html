ABOUT THIS BUILD

Online play, first steps.

This early build can connect two browsers and synchronize a simplified Vanguard table. It is not a complete Premium rules engine: card-specific abilities, complete rules enforcement, accounts, and persistent match storage are not included yet.

Decks stay in each browser. Players should use the same card library version. Peer connections may fail on some restricted networks.

Card art and imported card-text permissions still apply to any public deployment.
