# Menu artwork and display font

Character artwork and Planet Cray scenery are from the official Vanguard ZERO website:
https://vgzero-en.bushiroad.com/?p=270

Source artwork paths, under `https://vgzero-en.bushiroad.com/wp-content/themes/vgzero/`:

- Aichi: `img/pc/top/hd/kv_aichi-sendou-r2.png`
- Misaki: `img/pc/top/character/misaki-tokura.png`
- Kamui: `img/pc/top/character/kamui-katsuragi.png`
- Kai: `img/pc/top/character/toshiki-kai.png`
- Planet Cray: `img/pc/top/hd/bg_kv.jpg`

The character source images are retained intact. SVG viewports and clipping paths show the large posed character from each composite. These are decorative menu graphics, separate from playable cards. Copyright belongs to the respective Vanguard/Bushiroad rights holders; this project is unaffiliated.

Card artwork uses the existing numbered card assets and catalog. Menu associations: Aichi / Royal Paladin, Misaki / Oracle Think Tank, Kamui / Nova Grappler, Kai / Kagero.

Profile portraits also include linked character stand art for Emi Sendou, Ren Suzugamori, Asaka Narumi, and Kourin Tatsunagi from the official Cardfight!! Vanguard anime website, plus Chrono Shindou, Shion Kiba, Tokoha Anjou, and Koji Ibuki from TV Tokyo's official Vanguard G character page. These are remote images so the game bundle does not copy another site's artwork. Their appearance depends on those sites allowing image requests; character art remains the property of its rights holders.

Square profile crops for Toshiki Kai, Misaki Tokura, and Kamui Katsuragi are small local SVG viewports over the existing full character composites. The source art remains unchanged; the viewports center the character's face for the profile picker and match HUD.

The wordmark uses Barlow Condensed Black Italic by Jeremy Tribby, distributed under SIL Open Font License 1.1. Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed . License text is included in `OFL-BarlowCondensed.txt`. It is a custom Vanguard-inspired wordmark treatment, not a claim to use the official logo's proprietary typeface.
